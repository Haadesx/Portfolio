## Concept
A music player that knows how you feel. Instead of picking a playlist by hand, the app scans your face, works out your emotion, and plays a matching track.

## Vision Pipeline
We built a small CNN from scratch and trained it on the **FER-2013** dataset (Facial Emotion Recognition).

### Model Arch
- 4 Conv2D layers (32, 64, 128, 128 filters).
- MaxPooling and dropout (0.25) to curb overfitting.
- Dense output layer over 7 classes: Angry, Disgust, Fear, Happy, Sad, Surprise, Neutral.

## Integration
- **Frontend:** React application.
- **Backend:** Flask API hosting the TensorFlow model.
- **Workflow:** Webcam captures a frame -> sent to API -> model predicts "Happy" -> Spotify API plays "Upbeat Mix".

## Accuracy
The custom CNN hit **95.83% accuracy** on the test set, beating the pre-trained VGG16 transfer-learning attempts we tried for this lightweight task.
