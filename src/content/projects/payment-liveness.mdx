## Context

This HackHERS 2026 MVP explores verification workflows for bank and Solana payments. The résumé reports a Best Use Case of Solana API award.

## Approach

The React and TypeScript frontend captures a webcam challenge, shows verification scores and decision states, and provides retry and audit views. The broader stack includes Python services and an iOS client.

## Scope and limitations

This was a hackathon prototype; the repository does not establish real-world fraud detection performance.
