title: "lootqdm: Training Loop Toolkit"
---

## Context

lootqdm is a published Python package that presents training-loop progress as a game-inspired terminal interface.

## Approach

The toolkit tracks live training metrics and metric-based goals, with callback integrations for PyTorch and Keras. It supports persistent run profiles and automatically falls back to plain logging when a terminal interface is unavailable.

## Scope

The package is a training interface and tracking utility; its visual themes and progress indicators do not change the underlying model or establish training performance.
